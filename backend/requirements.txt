# Everything the backend needs to run, standalone.

# This used to list only fastapi/uvicorn and defer the rest to the repo's root
# requirements.txt, which made the service impossible to containerise from
# backend/ alone. The transitive set below is what app.py actually pulls in:
#
#   app.py -> src.transcription      -> rev-ai
#   app.py -> src.analyzer           -> anthropic
#   app.py -> src.transcript_cleanup -> anthropic
#   app.py -> generate_reels         -> export_pipeline -> src.marketing_doc -> python-docx
#   app.py -> dotenv                 -> python-dotenv
#
# python-docx is here only because analyze_with_claude imports
# normalize_recommendations from src/marketing_doc.py. Nothing writes documents
# server-side, but the import chain needs it at startup.
#
# Deliberately NOT included (verified unused on the backend's import path):
#   Pillow  — imported by no Python file in the repo
#   numpy   — only src/camera_sync.py, which the backend never reaches
#   ffmpeg  — the only callers are audio_processor/camera_sync; the backend calls
#             neither, so a slim Python base image with no ffmpeg is correct
